## 追加修复：轮播图片比例变形
- 根因：img 的 width/height 属性 + Bootstrap `d-block w-100`（只设宽不设高）→ 图片被强制拉伸成固定高度
- 修复：css/index.css 加 `.carousel-item img { width:100%; height:auto }`，恢复原始宽高比（width/height 属性仍保留防 CLS）
- 游戏轮播含 1:1（game.webp）与 16:9 混排，切换时高度自然变化属原始比例正常表现
